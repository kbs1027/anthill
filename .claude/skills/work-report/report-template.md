## 4. 테스트

사용자가 확인한 목록대로 쓴 테스트와 실행 결과다.

| 확인한 것 | 테스트 | 결과 |
|---|---|---|
| … | `FooTest.이름` | 통과 |

실행한 명령과 마지막 출력:

```text
$ cd backend && ./gradlew test
…
```
